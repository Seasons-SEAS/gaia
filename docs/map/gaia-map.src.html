    Next: production

    Everything above runs today, locally and on the demo host. For the public launch only the edges change: the RPC, where Core is hosted, the record and the channels. The turn logic, checks and receipts stay the same.

    Helius RPC next

    A paid Solana RPC: public RPC refuses Cloudflare Workers. The key lives in Cloudflare secrets. The cache and 20-minute warmer stay, so RPC load does not grow with visitors.

    gaia-core on Cloudflare next

    wrangler deploy with the Anthropic, ElevenLabs, AI Gateway and canary secrets, the seasons.wtf/api/gaia/v2/* zone route, 8/min and 60/h per IP. The Vercel demo is live meanwhile.

    Supabase next

    A record of turns with cost and mode, the team’s question queue, answer quality metrics.

    Human handoff next

    Handoff mode queues the question; a Python relay alerts the team on Telegram.

    More channels next

    The Telegram bot, the Terminal and MCP plug into the same Core: the same guards, checks and receipts.

    Languages and full eval next

    Turn ru/de/es/ja back on (one setting; the templates are ready) and run all 204 eval questions before launch, about $8–9, with a hard --max-usd ceiling.

    Jev awaiting access

    The Vercel AI Gateway still rate-limits the model. The fallback for the shadow judge is Workers AI.
